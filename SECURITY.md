# Security and responsible use

This project processes potentially sensitive voice recordings locally. A voice may constitute personal or biometric data depending on context and jurisdiction.

- Process only recordings you are authorized to use.
- Do not publish customer recordings or generated impersonations.
- Keep source datasets outside the repository.
- Review manifests before sharing because they contain local source paths.
- Never add API keys, credentials, or private endpoints to configuration files.

To report a vulnerability, contact `info@kraczewski.studio` without attaching confidential audio.
